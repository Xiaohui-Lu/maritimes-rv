Before comparing years

  • Grey points are not comparable. In those years the survey covered less than 90% of the region's area: see the data.
  • The trawl and vessels changed. Before 1982 the survey used the Yankee #36 trawl on the A.T. Cameron. Catchability differs between vessels and trawls, and no conversion factors are applied here, so long series are not strictly comparable across that line.
  • Values are per standard tow of 1.75 nautical miles. Totals in the data assume the trawl catches every fish in its path, so they are relative indices, not stock size.
  • Bottom temperature is the survey's own reading where it has one; where it has none, the reading of the CTD cast made at the same station fills in. Years still without readings: see the data.

Method, validation against DFO's code and published indices, and the data issues found: project README.

JSON API

Everything on this page is read from static JSON files with stable URLs, so code can use them directly. Series are columns of equal length; missing values are null.

EndpointContents
api/v1/meta.jsonRelease, source checksums, regions and a description of every field
api/v1/species.jsonEvery taxon caught, with its code, most frequently caught first
api/v1/index/<code>.jsonYearly index series for one species, by region
